# CLAUDE.md

Этот файл содержит указания для Claude Code (claude.ai/code) при работе с кодом в этом репозитории.

## Что это

Telegram-бот для русскоязычного чата сообщества «IT-завтрак Пхукет», написанный на aiogram 3. Все тексты бота, комментарии и лог-сообщения — на русском; новые тоже пиши на русском.

## Запуск

```bash
pip install -r requirements.txt   # версии зависимостей не зафиксированы; в Docker — Python 3.13
python3 -m TelegramBot            # единственная точка входа
```

Обязательны пять переменных окружения: `BOT_TOKEN`, `CHAT_ID`, `OPENAI_API_KEY`, `API_ID`, `API_HASH`. Они читаются через `os.environ[...]` на этапе импорта в `TelegramBot/config.py`, поэтому импорт *любого* модуля пакета без них падает с `KeyError`. По соглашению (см. README) в корне репозитория лежит скрипт `start.sh` (в .gitignore), который экспортирует их и запускает модуль. Важно: `docker-compose.yml` пробрасывает только `BOT_TOKEN`/`CHAT_ID`, поэтому контейнеру для старта нужно добавить остальные три.

Тестов и линтера нет (`test.py` — черновик в .gitignore; `.pytest_cache` — остаток от старых запусков).

## Ветки и деплой — осторожно

Jenkins (`Jenkinsfile`) собирает и деплоит на каждый push:

- push в `main` → **staging**-бот в отдельном тестовом чате
- push в `prod` → **production**-бот в настоящем чате сообщества

Деплой выполняется Ansible-плейбуками из отдельного репозитория `it-breakfast/it-breakfast-tg-bot-infra`. Чтобы пропустить пайплайн, добавь `[skip-ci]` в сообщение коммита.

## Архитектура

**Побочные эффекты импорта.** `TelegramBot/__init__.py` при импорте создаёт синглтоны уровня модуля: aiogram `Bot` + `Dispatcher`, APScheduler `AsyncIOScheduler` и клиент Telethon. Весь остальной код импортирует эти объекты (`from TelegramBot import bot`), поэтому порядок импорта модулей и переменные окружения важны везде. `__main__.py` лишь запускает планировщик, регистрирует хендлеры и стартует polling.

**Два Telegram-клиента.** aiogram `Bot` обрабатывает все обычные апдейты и отправку. Второй клиент — Telethon-*юзербот* (`client_userbot`, настоящий пользовательский аккаунт) — существует только потому, что Bot API не умеет читать историю чата: `helpers/userbot.py` через него забирает последние 100 сообщений для AI-саммари `/last100`. Имя файла сессии берётся из `config.BOT_NAME` (захардкожено `'userbot'` → `userbot.session`; переменная окружения `BOT_NAME` в start.sh ни на что не влияет). Файлы `*.session` — локальное состояние, они в .gitignore.

**Порядок роутеров критичен.** Роутеры регистрируются в порядке списка в `handlers/__init__.py`: `default_router, payments_router, ai_router, message_time_router`. Побеждает первый подошедший хендлер, а у `message_time_router` есть catch-all `@message()`, записывающий время последнего сообщения, — он должен оставаться **последним**, иначе проглотит все сообщения. Тот же принцип внутри `handlers/ai.py`: хендлер картинок («эй бот» + «нарисуй») объявлен раньше обычного «эй бот». (`middlewares/message_time.py` — неиспользуемая альтернативная реализация того же трекинга времени, она нигде не зарегистрирована.)

**Карта функциональности.**
- `handlers/default.py` — `/start`, `/qr` и `/link` (QR-коды для ссылок), ответ на закреплённые админами сообщения.
- `handlers/payments.py` — донаты в Telegram Stars (валюта `XTR`, пустой `provider_token`) по фразе «подогреть общак N»; pre-checkout-хук; админская команда `/refund <charge_id>`.
- `handlers/ai.py` — вызовы OpenAI через **Responses API** (`client.responses.create`, обёртка в `helpers/openai.py`), не chat completions. «эй бот …» → текстовый ответ gpt-4.1-mini; «эй бот … нарисуй …» → инструмент генерации изображений; `/last100` → история через Telethon + саммари gpt-4.1. Асинхронный контекст-менеджер `typing()` поддерживает статус «печатает…» во время долгих вызовов.
- `helpers/cron.py` — задачи по расписанию. Активно только напоминание по средам в 12:00; «оживлялка» молчащего чата намеренно закомментирована в `__init__.py` (см. коммит «disable mornin spam»).

**Время.** Всё работает по бангкокскому времени (UTC+7): таймзона планировщика и кастомный tzinfo `bangkok_tz` в `helpers/local_timezone.py`.

**Админы** — захардкоженные Telegram user ID в `config.ADMINS`, проверяются фильтром `IsAdmin`.
